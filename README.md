# Finanza Personale

App per segnare entrate e uscite, controllare conti e budget e seguire gli investimenti.
Ognuno entra con la propria email e vede solo i propri dati.

- `web/` – il sito (pubblicato su Cloudflare Pages: cartella di output `web`, nessun comando di build)
- `supabase/` – struttura del database (login, dati per utente, prezzi di mercato)
